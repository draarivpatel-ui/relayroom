RelayRoom is a synchronous four device communication relay simulated end to end in a single static page with zero backend dependencies. Four virtual devices, Orchid the phone, Maple the laptop, Juniper the tablet, and Cobalt the watch, join a shared room using a six character code and exchange notes, acknowledgements, and replies on a three second heartbeat. Every event enters one deterministic append only log with strictly increasing global sequence numbers and per sender counters. When you stall a device on the grid, the sweep evicts it after ten seconds of silence, and rejoining starts a fresh sender sequence. In the Message Lab, you can load presets for strict ordering, stale eviction, and replay windows, or step through custom scripts to read the exact decision trace. Below, the Code Validator checks room codes against a thirty one character alphabet and executes a one thousand code mutation sweep in milliseconds.
